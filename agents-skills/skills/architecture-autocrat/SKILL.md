# architecture-autocrat

## What this skill owns

The autocrat's instruments for enforcing the contract: the design mode that gives the tree no vote, the ruling channel that gives the implementer no vote, and the reviewer brief that roasts the file hostile.

`architect` routes a procedure to this skill; the table names the file that carries it.

| File | Covers |
|---|---|
| `references/design-autocrat.md` | procedure 1's autocrat mode - the steps above the shared four, with the tree given no vote |
| `references/maintain-autocrat.md` | procedure 3's channel where the architect reads no code and only rules |
| `agents/reviewer.md` | the brief both procedure 2 lenses receive: the prescriptive purpose, the arguments that are invalid against this file, and each lens's checks |

**Read the file the table names for the procedure in hand, before running that mode.** Each carries steps and gates the procedure's own section does not restate.

## Which skill owns the shared ground

**Quote every format rule from `architecture-md`, never from a copy here.** All three files grade findings against its sections, and a second copy drifts from the only home.
