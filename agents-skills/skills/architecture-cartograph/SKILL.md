# architecture-cartograph

## What this skill owns

**Read `references/design-cartograph.md` before the first question, rather than running the mode from memory.** It carries every step above the shared four - telling a transcription from an inventory, and whether a disagreement is drift or a wrong statement.

**Load `architecture-md` for the format before writing any of the file, never a reconstruction from memory.** Its own opening points at the format file, whose Contents line names every section it covers.

**Work the mode's steps above `architect`'s four shared design steps, never instead of them.** The coverage questions stay open after the map - a decomposition says what the layers are and nothing about threading, failure or data ownership.

## Which runs this skill hands to architect

**Given a decomposition the user is still deciding, hand the run to `architect`'s design modes.** Cartography transcribes a decision already made, and a tree read without one is an inventory wearing a contract's format.

**Hand what follows the finished map - the roast, boundary rulings, drift audits - to `architect` as well.** They judge or police a contract rather than write one, and the roast is procedure 2 there.
